## 本轮增加

- 星月连连看：36关、六章、最多两次转弯与外围绕路、石头/留白地形、提示/重排、自由选关、星星成绩、续局。
- 小院消消乐：20关、相邻交换、三连与落子连消、4/5连加步、分数/指定图案目标、提示、即时重试、过关最好分数与续局。
- 六项兴趣手册：香草香包、鸟声手帐、压花小册、纸星灯、明信片、浆果酱。每项三个持续步骤，记录开工背景、材料、进度和成品来源。
- 她会自主挑兴趣；未完项目、近期愿望、精神和刚完成的作品影响选择。没有待研究的梦种时不反复假装研究，阅读的相对倾向降低。
- 开工取材料一次；暂停、一起玩、回来继续都保留进度。果酱完成增加茶点。手册保留最近36件成品与累计件数，最近一件显示在工作桌旁。
- 内置12种棋盘小图标，不依赖系统表情字体；加大手机棋盘点击格；修复数独键盘填数后的焦点丢失。
- v2/v3→v4迁移，同一存档键、迁移前备份，原梦种、书签、性格、旧小游戏与收藏保留。

## 仍可玩

小屋、小院与各自寻路；场景小金点；读书、茶、休息、采集、厨房、整理、看鸟、观星、野餐；材料→茶点→野餐、添水→小鸟停留；收藏摆放和灯光。

“一起待会儿→玩会儿游戏”共六种：五子棋、数独、照片交换拼图、记忆牌、连连看、消消乐。收起游戏后接回她的生活。

设备日期与时钟、跟随时区的昼夜、确定性的游戏天气；梦种→提案→学习→制作/植物→成长→便笺；分层记忆、可解释的因果。离线按事件时间结算，不要求电脑常开。

手动ChatGPT创作桥接、本地规则、D盘便携EXE、磁盘存档、网页缓存、导出导入与损坏保护。AGENTS、README和长期知识库持续维护。

## 别人打开会怎样

GitHub Pages发布程序与公开美术。朋友在自己的浏览器开始自己的世界，进度和梦种分开；初始人物仍是同一个小罗模板。同一个浏览器共用同一份存档。未建立账号或自动云同步，换设备用导出/导入接档。

角色自定义、明信片分享与串门是后续提案，见 design/05-hobbies-and-arcade.md；本轮按制作人决定优先丰富自己的玩法。

## 尚未实现或未验证
