## 已实现

- 保持森林小屋与原创魔女画风；自主寻路、点击走动，速度从79提高到108世界单位/秒。
- 数小时阅读与章节内容、喝茶/休息/研究等持续活动；打断、恢复、离线按时间结算。
- 天气、精力、性格倾向与知识条件影响行为，保存原因、候选分数及因果记录。
- 梦种原文输入、本地组合方案、玩家确认、研究知识、制作实体物件、原文来源回看。
- 植物受时间与水分影响生长，可浇水，长成后收到旧温室便笺。
- 梦种/经历/长期知识分层，手记只保留重要进展，普通走动不重复刷条目。
- 可续盘五子棋、选点确认、白棋局部AI、悔棋、收起棋盘继续原活动。
- 手动ChatGPT创作桥接，JSON校验后才采纳；默认不外发梦种。
- 存档校验、导出导入、损坏存档保护与备份恢复入口。
- D盘Windows便携EXE、本机服务、D盘玩家存档及浏览器资料。
- 静态网页文件、manifest与service worker；适合后续托管。
- 长期知识库、AGENTS规则、README、索引、架构与想法收集流程。
