# 技术决策记录

## ADR-001：手机优先的一套网页内核

选择原生 JavaScript + Canvas 2D + HTML/CSS，无npm运行依赖。已有像素场景适合小型2D Demo；同一份game文件可用于电脑本机服务和GitHub Pages。以后是否转引擎由需求决定，不承诺零成本迁移。

## ADR-002：Windows EXE作为本地入口

C#/.NET Framework WinExe启动本机静态服务，Edge/Chrome独立应用窗口，托盘管理。无需Python/Node才能游玩。游戏、专用浏览器资料、磁盘存档均放在项目目录。EXE不在iPhone运行，手机使用网页。

## ADR-003：世界与AI分离

时间、规则、因果、记忆由本地引擎负责。AI当前通过人工复制JSON提案使用会员账号，无API账单。自动AI服务和账户云同步分别是未来适配层。

## ADR-004：用真实时间，演示链条局部加速

读书等持续活动按真实时间；梦种从素材到可见物件的首次链条缩短到分钟级，以便快速验证。不能把短循环反复文字当作生活。

## ADR-005：D盘为唯一活跃项目

主项目D:/WitchLife。早期C盘内容迁入archive/v1，原目录只留位置说明。工具系统自身的缓存由工具管理，不属于游戏运行依赖。

## ADR-006：GitHub保存代码与静态发布，存档另行管理

GitHub账号moriarimota已连接；需要独立仓库，不修改用户其他项目。Pages仅承载静态game文件，不自动成为私密云数据库。桌面/手机目前以导出导入转移存档。
