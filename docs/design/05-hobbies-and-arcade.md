# 兴趣手册与消除游戏 · v0.4

来源：2026-09-29 制作人试玩反馈。优先丰富自己的生活；增加消消乐、更多关卡的连连看。多人世界暂作设计储备。

## 一段能继续的生活

六项兴趣各有三步，进行到哪一步、是否已经领过材料、开工时的天气和梦种来源都入档。一次动作结束后只推进一步，她再结合精神、未完项目、近期愿望和刚做过的事情选择下一件事。不会每次打开随机改写原因。

| 兴趣 | 三个步骤 | 前提与产出 |
| --- | --- | --- |
| 香草香包 | 晾香草 → 缝月牙小袋 → 装入系绳 | 开工消耗香草1份，完成一件挂饰 |
| 鸟声手帐 | 窗边记录 → 画声纹 → 装订 | 完成一本带时间天气背景的手帐 |
| 压花小册 | 挑选叶片 → 画图鉴 → 装入册中 | 开工消耗香草1份，完成一本小册 |
| 纸星灯 | 折星星 → 描花纹 → 挂到窗边 | 使用常备手工纸，完成一件星灯摆件 |
| 留给你的明信片 | 画插画 → 写两句 → 收进信匣 | 开工时固定最近梦种的来源；信只在本地收藏 |
| 浆果酱 | 洗浆果 → 慢熬 → 装罐贴签 | 开工消耗浆果1份，完成收藏并增加茶点2份 |

她自己做每步20–40分钟。玩家邀请新开始的一步采用1分钟Demo时长；加入已开始/暂停的同一兴趣会恢复原进度，不另起一个重复项目、不重复扣材料。未完成项目与玩家指定的“近期小愿望”提高倾向，精神不足先休息。刚完成同类作品的12小时内降低重新开工倾向。没有待研究梦种时不再反复假装研究同一片叶子，阅读倾向也适当降低。

入口：一起待会儿、看看附近、工作桌、小小收藏 → 兴趣手册。完成的最近一件会显示在工作桌旁；点击进入手册。作品保存三次活动ID和梦种来源，第一次学会工艺进入知识，成品进入重要经历。普通每一步只进入有限因果日志，不刷满手记。

手册保留最近36件作品，六项累计件数继续保留。当前采用已有书/挂饰/食物图集表示成品种类，尚未为每件手作绘制专属图像。此限制在界面与文档明确，不宣称无限内容。

## 连连看

36关，六章：窗边初遇、香草小径、雨后蘑菇、月光邮局、星图书房、森林茶会。棋盘从4×4到6×8，包含石头、四角留白、中间通道；图案种类逐步增加。所有关卡可自由进入。

同图案可以通过最多两次转弯的折线连接；棋盘外围允许通行，其他图案和石头阻挡。先构造一条完整移除路径，再分配成对图案，保证初盘至少有一种解法。玩家中途选择可能进入无路局面，此时自动重新摆好剩余图案，不删除或额外生成图案。可主动提示与重排，无倒计时、体力或失败等待。

过关记1–3颗星：零次主动帮助为3星，1次为2星，2次以上为1星；自动解困不扣星。最好成绩留在关卡册。同关重玩会重新生成初盘；未完成局保存棋盘、随机数、消除数与帮助数。切换另一关或重新开始先确认替换当前棋盘，历史成绩不变。

## 消消乐

20关，7×7棋盘。相邻交换形成横竖三连后消除、下落和补充；新的三连继续连消。无效交换撤回，不扣步数、不消耗随机状态。基础得分为每颗10分，连消倍率最高5倍。一次交换中最长连线达到4颗返还1步，5颗或以上返还2步；每次交换最多返还2步。

初始步数30到27步，目标分数465到1700分。每3关增加指定图案收集目标；第8关起从5种图案增加到6种。初盤不带待消三连，并至少有一个合法交换。无路时自动重排；提示与主动重排也可用。步数耗尽可立即重试，无体力系统。

每局棋盘、随机状态、剩余步数、收集数和分数入档；每关保存最好过关分数。结算先写稳定棋盘再播放短动画，切到后台或关面板不会留下一半消除状态。

## 别人来玩这件事

当前发布的是游戏程序与公开美术，GitHub Pages不保存玩家的私人梦种。朋友在自己的浏览器打开同一网址，会建立自己的本地世界；现阶段仍使用同一套小罗初始角色与规则。共同浏览器则共用存档。没有账号、联机或自动跨设备同步。

未来建议分两步，均未实现：

1. 开始新世界时选择名字、外形模板、性格偏好；角色实例与世界规则分离，保留制作人的小罗设定作为她自己的默认世界。
2. 玩家主动选择寄明信片或分享物件，再考虑有限串门。私人梦种原文默认不发送；共享内容采用显式导出结构。实时共同世界需要身份、服务器与冲突规则，不能把静态网页上线称为已经联机。

本轮不增加账号负担，不向服务器上传日记。
