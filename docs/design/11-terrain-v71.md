# 室外地表与手机交付 v0.7.1

制作人 2026-10-04 反馈：室外地图突兀、粗糙；希望尽快在 iPhone 上玩到，询问 App 和 GitHub 重连。

## 采用的改动

- 地表使用四象限手绘像素素材：草地、土路、石铺地、水面；提示词保存在 design/terrain-v2-prompt.md。
- terrain.js 根据 village.js 的道路线段生成连续路面，交叉口融合；边缘有草土过渡。门前与长椅脚下有石铺地。
- 为建筑、树木、花丛绘制接地阴影；河岸增加石块、芦苇，木桥和栈桥加木纹。
- 修正道具图集中花丛夹带长椅边角的问题；顶部树冠位置、尺寸有变化。
- 碰撞、门口、河流阻挡和桥梁通行坐标保持不变，存档 schema 仍为 6。
- 小游戏布局用微任务调度，避免后台或恢复窗口时等待被冻结的动画帧。

## 手机形式

本轮交付目标是可添加主屏幕的 PWA，支持独立窗口和首次缓存后的离线游玩。它不提供系统后台永久运行、自动云同步或 IPA 安装包。原生封装仍可在未来推进，需要苹果签名、构建和安装环节。

本机素材使用离线白名单，GitHub Pages 只发布 game/。个人角色图、梦种、存档不进入仓库或部署包。跨设备仍用导出/导入。
