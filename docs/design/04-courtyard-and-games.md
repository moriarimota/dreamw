# 小院与游戏桌 · v0.3

来源：制作人 2026-09-21 要求增加一起玩的游戏、更多生活与场景互动；天气选择“先使用游戏天气，之后再设置城市”。本页记录已落地规则，不把将来河岸/NPC提案写成现有功能。

## 两种加入方式

点“一起待会儿 → 玩会儿游戏”，打开五子棋、数独、交换拼片、星月记忆牌。真正开始一局才暂停她当前的活动；看菜单时她仍在生活。收起题纸或棋盘，她从同一本书、同一段制作进度继续。关闭网页后，下一次按离开时的书签恢复她的日常并追赶时间；小游戏本身可续玩。

点场景的小金点或“看看附近”，加入具体事情。角色自主活动按分钟或小时持续；共同采集、厨房、整理、看鸟、观星、野餐采用 90 秒试玩时长。没有打卡要求或限时奖励。她可自己进入小院；玩家独自切场景只是改变视角，不会把她瞬移到正在查看的地方。“去她身边”重新跟随她。

## 有结果的日常

| 事情 | 前提 | 世界变化 |
| --- | --- | --- |
| 采香草 / 摘浆果 | 白天 6–21 点、精神不少于25 | 完成带回2份对应材料，库存每类上限24 |
| 煮香草茶 / 烤浆果饼 | 对应材料至少1份，精神高于18 | 开始时取1份材料，完成时得到2份茶点；暂停续做不再扣材料 |
| 小院野餐 | 7–20点、不下小雨、有茶点 | 开始取1份茶点，活动恢复精神并提高屋里舒适度 |
| 整理屋子 | 精神不少于25 | 完成提高舒适度，第一次留下经历 |
| 给鸟添水 → 看鸟 | 6–20点可看鸟 | 添水至3；看鸟结束时消耗1份水并增加1次停留记录 |
| 看星星 | 19–5点、没有小雨 | 第一次学会一条星迹知识 |
| 换一本书 | 选择已有书籍 | 保留旧书进度，读新书的章节 |
| 改摆收藏 / 调灯 | 即时 | 改变物件实际显示位置 / 夜间亮度，并入档 |

行为倾向还考虑天气、精神、性格、库存和刚做过什么，最后带权抽取。系统先检查硬条件，再记录选择原因；完成事件保存活动来源ID。普通重复家务只入因果事件，手记记录首次里程碑，避免刷屏。初始材料是迁移礼物和试玩起点，不是每天刷新奖励。

## 小游戏规则

- **五子棋**：沿用15路棋盘和局部评分对手；选点后确认、悔棋和续局。
- **数独**：9×9，轻松题约43个给定、标准题约34个给定。随机数字/行列组合后逐格移除，并以求解器验证唯一解。难度是给定量分档，尚非人工技巧难度评级。可写笔记、擦除、检查、要提示。提示是直接给一格答案并提醒规则，尚无分步骤教学。
- **拼一张小世界**：小屋/小院照片、3×3或4×4块。点两块交换位置，可看原图。当前为方形交换拼片，不是异形拼图或拖拽拼图。
- **星月记忆牌**：12张卡、6对图案；两张翻开后等待0.8秒判定。收起时停止计时，重新打开再处理待判定的牌。

每种游戏保存独立一局；换局会先提示确认。完成记录以题目/棋局标识去重。小游戏不产生可刷取的经济奖励。

## 时间与天气

页首显示设备的真实日期和时分。昼夜条件跟随设备时区；存档带UTC偏移，打开时更新为当前设备偏移。天气以世界创建时间和6小时时段确定，属于**游戏天气**，与城市实况无关；重复打开不会重抽。夜间调暗、晴夜光点、小雨雨丝会影响画面，减少动态效果偏好会停用粒子动画。

城市选择、实况天气API及失败回退尚未接入。不同设备需要导入同一世界存档才能共享世界创建种子；当前没有账号云同步。
