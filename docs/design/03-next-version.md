# 下一轮：让家里处处有事可做

来源：2026-09-21制作人反馈“满意，但单调，活动、场景和场景内互动偏少”，并授权先完成手机试玩。

当前顺序：完成网页发布和存档迁移，建立v0.2试玩基线；优先丰富屋内生活，再扩出门后的生活半径。以下细节为开发提案，尚未实现。

| 地点 | 她自己做 | 玩家加入 | 留下什么 |
| --- | --- | --- | --- |
| 书架 | 根据兴趣选书 | 同读一页、换书、分享想法 | 书签、知识、研究动机 |
| 炉边 | 根据精力与材料准备茶点 | 选配料、一起等 | 材料消耗、可分享的茶点 |
| 窗边小园 | 看天气、照料植物 | 浇水、记录新叶 | 植物状态、观察笔记 |
| 工作桌 | 研究梦种、整理札记 | 选做法、参与一道步骤 | 有选择差异的物件与知识 |
| 收藏架 | 整理旧物、想起经历 | 换摆放、翻看来历 | 陈设变化、与新梦种联系 |

下一处地点提案：先小院，再从河边钓点与旧温室中选一个展开。一段生活应能接成“雨后新叶 → 采集观察 → 查书 → 发现用途 → 一起制作 → 成品留在家里”。

每个新互动要改变真实状态，有前提、有结果、可中断恢复；不能只增加随机台词。保留同一活动的自主进行与玩家加入。扩展内容数据，兼容v0.2存档，不增加打卡、离线惩罚或强制劳动。
