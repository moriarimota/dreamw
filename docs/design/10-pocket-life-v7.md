# 口袋里的生活 · v0.7 预览

来源：2026-10-03，制作人希望 iPhone 17 Pro 可本地玩、角色更鲜活、明信片成形、扩充小游戏。

## 本轮采纳

- 手机采用可安装到主屏幕的离线 Web App。首次联网下载，之后核心游戏不依赖服务器。关闭时不在 iOS 后台持续模拟，重开按事件时间结算。
- 保留原有地图和角色美术；读书翻页、写字笔尖、热茶蒸汽与轻微呼吸属于表现层，不制造资源、记忆或活动结果。遵守减少动态效果设置。上传的单张角色图片仍没有完整骨骼或四方向动作。
- 手作明信片走原有三步流程。开工时保留天气、时段、梦种来源；成品有插画正面、信文背面、信匣、未读标记和 PNG 下载。信文为本地模板与真实素材组合，不是在线 AI 生成。旧明信片展示原有制作记录，不补编往事。
- 邀请开始的新手作，每步约一分钟，前一步结束后继续下一步；已开工项目仍承接原进度。路程单独计算，梦种已承诺的学习/制作可以优先插入。读书等暂停计划在手作完成后恢复。
- 新增像素数织（5×5、8×8）和星砂合成（2048）。棋盘独立入档，收起后可继续；完成时记录一条共同经历。

## 数织与合成的规则

数织来自精选像素图及镜像/转置，并检查行列约束的唯一解；有多解时提供已知格。涂色、标空、擦除、撤销、单格提示均可用，无倒计时。现有题库为有限图案组合，后续可继续补图。

合成支持触摸滑动、方向按钮及键盘。同一方块每步最多合并一次，有效移动后才生成新方块；保留随机状态与移动序列，可撤销和重播校验。2048 后可继续，最多保留 12000 步。

明信片仍属于手作收藏，和其他手作共用最近 36 件容量。可下载 PNG 或导出整份存档留存；没有邮件发送、云相册或分享上传。

## 离线与更新

`offline-manifest.js` 列出 51 项公开运行资源。Service Worker 完整缓存成功才安装；设置页逐文件检查后显示“离线已就绪”。导航读取安装版本的入口，带版本的资源按精确 URL 命中缓存，私人存档 API 从不缓存。

新版本下载完等待用户在设置中更新，先等待保存成功再激活和重载。网络失败继续旧版。存档键和世界 schema 仍为 v6，新增字段采用缺省值兼容。

提供持久存储申请和 JSON 导出；浏览器是否授予由系统决定。Safari 与主屏幕入口可能有独立存储，建议确定入口后导入。iPhone 真机安装、文件分享和飞行模式仍需要实机验证。

## 验收边界

规则、存档、资源清单与离线处理可自动测试。角色动作观感、棋盘在真实手机上的触摸效果需浏览器/真机验收。本轮浏览器接口连续超时，尚不能宣称视觉通过；公网发布还缺有效 GitHub 授权。
