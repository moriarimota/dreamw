# v0.6.1 画面与操作调整

来源：制作人的七张试玩截图，以及“看起来仍是同一只脚”的反馈（2026-09-30）。代码已实现，实际浏览器验收尚未完成，不能把本页作为视觉验收通过的记录。

## 行走

- 原精灵表正面第二、三帧都抬同一侧脚；右向画面按均匀格切图会混入邻格像素。保留原素材，以明确坐标裁帧。
- 使用站立帧的身体，左右腿独立、反相运动。侧向站立帧两只靴子有重叠，腿部取自迈步帧的完整靴子，围绕站立髋部位置运动。身体不会左右镜像翻转。脚底锚点统一，步幅由移动距离推进。
- 新生成的替代图仍然重复同侧抬脚，已经弃用；未作为运行素材、未进入发布清单。
- 寻路格为16世界单位，速度190单位/秒；短起停70ms。方向键斜向受阻时沿可行方向滑动，近障碍点击落到附近可站位置。固定地点的绕行路线缓存、A*优先队列降低计算量。
- 旧档路程继续使用原有起止时刻；更快速度仅用于新路程。到达时直接使用目标坐标，避免浮点误差残留。

## 界面

标题、时间、天气改为紧凑浮动信息；底部状态与按钮缩小。房间按视口居中，宽屏左右留白对称。地点名称按屏幕尺寸绘制，靠近时显示，站到标记上时让开人物。行走不显示工作进度条。

小游戏的说明默认折叠，棋盘按可用高度计算尺寸，桌面操作区在侧面，窄屏在下方。移除“柔和配色”和手动放大按钮。棋盘与核心操作应在同一屏，复杂说明允许独立滚动。新增布局由play-layout.js和polish.css负责。

文案使用“生活”。删除“她记住的是……不是……”等无助于当前操作的说明，不改写玩家输入的梦种原文。

室外地面降低大块色差，路径先整体铺底再铺面，减少接缝与重叠描边，补细草。仍使用现有建筑与树木素材，地图美术还需要实际试玩再判断。

## 钓鱼

河面绘制浮标、鱼线和鱼影；距离变化带动浮标靠岸，张力影响鱼线和鱼竿弯曲。咬钩后可点击河面起竿，按住收线连续拉动，松线、稳住继续有效。切走、松手或窗口失焦立即停止连续收线。继续使用原有鱼种、资源与存档结算规则。
