# 在 iPhone 上玩梦乡

v0.7.1 离线版已在 D 盘完成，公网发布状态以 `STATUS.md` 为准。

新版发布后：

1. 用 Safari 打开 https://moriarimota.github.io/dreamw/ 。
2. 分享 → 添加到主屏幕；如显示“打开为网页 App”，保持开启。
3. 从桌面新图标进入游戏，打开右上角设置，保持联网直到显示“离线已就绪 · v0.7.1”。
4. 关闭后打开飞行模式，再从图标进入，检查地图、小游戏和存档能继续。

这是安装到主屏幕的离线网页应用，不需要上 App Store 或签名安装 IPA。游戏首次完整下载需要网络；模型自动生成、账号云同步尚未接入。

## 电脑的生活带到手机

电脑设置 → 导出这段生活 → 把 JSON 文件传到手机 → 在主屏幕游戏的设置里选择存档并确认导入。两端各自保存，不自动同步。清理网站数据、更换手机前导出；“保护本机存储”按钮可以向浏览器申请持久存储，是否授予由系统决定。

## 以后更新

有网时打开设置 → 检查游戏更新。更新先下载完整资源、保存生活，再切换版本；下载失败仍保留当前缓存。若显示下载尚未完成，稍后重新检查即可。

## 本轮验证

已通过 5 项离线规则测试：完整素材清单、逐文件检查、断网时页面及素材命中缓存、私人 API 不缓存、更新等待激活、失败安装保留旧缓存。浏览器界面回归 9/9，覆盖 320、390、402、1280 宽度；未在 iPhone 17 Pro 真机上执行。

参考：[Apple：把网站添加成 App](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios)、[WebKit：存储策略与持久存储](https://www.webkit.org/blog/14403/updates-to-storage-policy/)。
