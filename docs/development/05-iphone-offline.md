# 在 iPhone 上玩梦乡

v0.8.1 已于2026-10-05发布到公网，发布记录见 `STATUS.md`。

首次在手机上打开：

1. 用 Safari 打开 https://moriarimota.github.io/dreamw/ 。
2. 分享 → 添加到主屏幕；如显示“打开为网页 App”，保持开启。
3. 从桌面新图标进入游戏，打开右上角设置，保持联网直到显示“离线已就绪 · v0.8.1”。
4. 关闭后打开飞行模式，再从图标进入，检查地图、小游戏和存档能继续。

这是安装到主屏幕的离线网页应用，不需要上 App Store 或签名安装 IPA。游戏首次完整下载需要网络；模型自动生成、账号云同步尚未接入。

## 电脑的生活带到手机

电脑设置 → 导出这段生活 → 把 JSON 文件传到手机 → 在主屏幕游戏的设置里选择存档并确认导入。两端各自保存，不自动同步。清理网站数据、更换手机前导出；“保护本机存储”按钮可以向浏览器申请持久存储，是否授予由系统决定。

## 以后更新

有网时打开设置 → 检查游戏更新。更新先下载完整资源、保存生活，再切换版本；下载失败仍保留当前缓存。若显示下载尚未完成，稍后重新检查即可。

## 本轮验证

已通过5项离线规则测试。v0.8本地界面回归19/19，覆盖320、402、1280宽度；发布后65个公网资源与本地一致。公网浏览器预览超时，未在iPhone 17 Pro真机上执行。完整验证边界见 `07-v8-verification.md`。
