## 一次迭代的入口

把想法记为 IDEA 编号 → 找受影响模块 → 明确“已决定/提案/暂缓” → 描述一段可玩的前后变化 → 实现及测试 → 更新状态和日志。一个章节已足够解释的内容，不复制到所有文档里。
